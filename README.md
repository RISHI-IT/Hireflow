🚀 HireFlow — Full-Stack Job Portal

HireFlow is a modern full-stack job portal designed to connect candidates and recruiters through a simple, efficient, and secure hiring platform.

The application provides separate workflows for candidates and recruiters, allowing candidates to discover and apply for jobs while recruiters can create and manage job postings and handle applications.

🌐 Live Demo

Live Application: https://hireflow-frontend-1.vercel.app/

---

✨ Features

👨‍💼 Candidate

- User registration and login
- Secure JWT authentication
- Browse available job opportunities
- View detailed job information
- Apply for jobs
- Track submitted applications
- View application status
- Candidate dashboard

🏢 Recruiter

- Recruiter registration and login
- Create and publish job postings
- Manage posted jobs
- View candidate applications
- Accept or reject applications
- Recruiter dashboard

🔐 Authentication & Security

- JWT-based authentication
- Protected API endpoints
- Role-based application workflows
- Secure frontend-to-backend API communication

🏗️ Project Architecture

HireFlow
│
├── Frontend
│   ├── React.js
│   ├── React Router
│   ├── Axios
│   └── Responsive UI
│
└── Backend
    ├── Django
    ├── Django REST Framework
    ├── JWT Authentication
    └── PostgreSQL

The frontend communicates with the Django REST API through Axios, while PostgreSQL is used for persistent application data.
